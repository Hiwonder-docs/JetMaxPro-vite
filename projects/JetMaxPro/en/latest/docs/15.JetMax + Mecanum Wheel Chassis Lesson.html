15.3 Lesson 4 Handle Control ​

Step 1: insert the handle receiver to any USB port on Jetson Nano.

Note: please insert the handle receiver before starting the robot.

Step2: prepare two AAA batteries. Then insert them to battery slot. Please don’t invert ‘+’ and ‘-’ poles.

15.3.1 Device Connection ​

Step 1: start JetMax Pro

Step 2: turn on handle. At this time, two LED lights on it will flash at the same time.

Step 3: wait for a few seconds. JetMax Pro automatically matches with the handle. Green LED light will be on once they match successfully.

If handle does not connect to the robot within 30 seconds after turned on, or there is no operation on handle within 5 minutes after connection, handle will enter sleep mode. If you want to wake it up, press “START” key.

15.3.2 Introduction to Mode ​

There are two control modes, namely coordinate mode and individual servo mode. Handle enters individual servo mode by default after connection.

Individual servo mode: you can control servo separately on robot arm to rotate.

Coordinate mode: you can control robot arm to move in the direction of X, Y, Z axes.

Way to switch mode: press “SELECT” key. When handle emits sound, it means the mode is successfully switched. When sounding once, it is switched to coordinate mode. When sounding twice, it is switched to individual servo mode.

15.4 Lesson 5 Follow Line to Sort ​

Before this game, you need to follow the file in ‘17. JetMax + Mecanum Wheel Chassis Lesson->Lesson 2 Position Calibration’ to calibrate position, otherwise game effect will be influenced.

Then set the scenario with red tape as pictured. JetMax Pro drives along middle tape, and tapes at both ends respectively mark the position where robot starts detecting tags and places tags.

The middle red tape should be at least 80cm long to ensure enough motion space for JetMax Pro, and the distance between middle tape and tapes at both end should be 10cm.

15.4.1 Program Logic ​

JetMax Pro is programmed to recognize line and tag through the camera while moving along the line. Then it picks tag block and transfer it to the other end.

It keeps going forward to recognize the tag. To let JetMax Pro recognize tag and line, the program converts RGB color space to Lab first. Following, perform image binarization, open operation and close operation to get the contour only in target color.

For tag recognition, the program calls AprilTag library function to detect AprilTag to get tag ID, coordinate of its four corners and coordinate of its center.

In line following, three tapes you set separate the image into three parts, including top, middle and bottom, which accelerates processing. Robot can distinguish horizontal line from vertical line according to the line width.

When recognizing horizontal line, it starts detecting tags and suck tags in order. Then it moves along line and stops when detecting the horizontal line on the other end. Lastly, place the block to specific position according to tag ID.

The source code of this program is stored in ros/src/chassis/scripts/patrol_sorting.py

15.4.2 Operation Steps ​

  1. Start JetMax Pro, then connect your computer to WiFi generated by JetMax Pro. In general, WiFi name starts with HW.

  2. Connect to system desktop through NoMachine. Double click to open terminal. For how to install and use NoMachine, please refer to ‘7. Robot System Remote Connection’. Robot system is as pictured.

  3. Click or press ‘Ctrl+Alt+T’ to open terminal.

  4. Run command “cd ros/src/chassis/scripts” to enter the directory storing game program

  5. Input command “./kill_app_funcs.sh” to stop APP auto-start service.

  6. Input command “rosrun chassis patrol_sorting.py” to start following line to sort. It takes about 30s to start the game. Please be patient!

  7. Input command “./restart_app_funcs.sh” to enable APP service. Do not skip this step, otherwise other games will be influenced.

15.4.3 Program Outcome ​

JetMax Pro starts line following first. When it recognizes horizontal line based on line width, it starts tag detection. Once detecting tags, JetMax Pro puts down its camera, then detects location of the tag on the camera returned image. After that, suck the block, then turn around to transfer the block to the start.

15.4.4 Program Analysis ​

Import Function Library ​

Import OpenCV, time, mathematics, thread and inverse kinematics libraries. You can call functions in the library in this format, ‘library name + function name(parameter, parameter...)’.

time.sleep (0.01) means that ‘sleep’ function in ‘time’ library is called. The function of sleep() is to delay.

There are some built-in libraries in Python, such as ‘time’, ‘cv2’ and ‘math’, and you can directly import and call the library. Or you can write a library on your own.

‘std_srvs.srv’ is a library of ros service type.

Define Global Variables ​

Define global variable to set ‘ROS_NODE_NAME’, ‘TAG_SIZE’, ‘TARGET_POSITIONS’ and ‘TRACKING_POSITION’.

Instantiate ‘Misc’, ‘chassis’, ‘motor’ and ‘at_detector’ function for the convenience of calling.

Analyze Main Function ​

In python, ‘__name__ == ’__main__:’’ is main function of the program. The program firstly call rospy.init_node() function, and initialize node with ros. Initialization configuration includes operations that make robot arm recovery initial posture and read color threshold file. Generally, there are also configurations such as ports, external devices, and timed interrupts, which are completed during initialization.

Instantiate ​

As names of some function libraries are too long, you can instantiate the function library making it convenient to call functions. After instantiation, you can directly call function in this way, ‘’jetmax.function name(parameter, parameter...)

Publish and Subscribe to Topic ​

Read color threshold file, and delete ‘white’.

Subscribe to and publish topic with ros.

Read Camera Image ​

When the program jumps into a loop, it process image with image_proc() function.

Process and Analyze Image ​

Confirm target to be detected through variable ‘state.skip’. Initially, it detects line.

Line Following ​

Obtain Image ​

Obtain new image and use cv2.resize() function to scale the image. Perform Gaussian filtering and remove noise

The first parameter ‘frame_resize’ represents the imported image.

The second parameter ‘(3, 3)’ indicates the size of Gaussian kernel. Larger kernel results in greater filtering, and makes the output image fuzzier and computation more complicated.

The third parameter ‘3’ refers to the size of variance allowed around its average in Gaussian filtering. The greater the value, the greater variance allowed around its average.

Segment ​

Image will be segmented into three parts, which can achieve faster and preciser processing as well as better recognize where to turn.

Convert Color Space ​

Each frame of the images read by OpenCV is arranged by pixels composed of three color components, B, G and R. Three primary colors (red, green and blue) will change greatly under different lighting.

Call cv2.cvtColor() function to convert RGB color space into Lab color space.

Image Binarization ​

Next, process image to extract the contour and confirm position. Next, process real-time image through OpenCV.

All pixels in the image are represented with 0 and 1. Pixels with a value of 0 are black, and pixels with a value of 1 are white. This approach is called image binarization.

Call cv2.inRange() function to realize image binarization. This program is as follow.

Open Operation and Close Operation ​

To reduce interference and smooth the image, perform open operation and close operation in sequence after image binarization. The purpose of corrosion is to remove the burr at the edge of image. Goal of dilation is to expand the edge of image so as to fill in non-target pixels at the edge and inside the target.

Locate Contour ​

The final goal of previous operations is to locate the target. Next, separate black and white area to locate the target.

Find four vertices of the smallest rectangle, then draw the rectangle through these four vertices.

Tag Detection ​

Process Image ​

Call ‘cv2.cvtColor’ functions to process image. Convert RGB image to gray image.

The first parameter ‘np.copy(img)’ represents the pictured to be converted.

The second parameter ‘cv2.COLOR_RGB2GRAY’ represents convert RGB image into gray image. ‘cv2.COLOR_BGR2RGB’ means that convert BGR into RGB format.

Recognize and Display ​

Next, call “at_detector.detect” function to detect AprilTag so as to get coordinate of four corners of AprilTag and coordinate of AprilTag center. This program is as follow.

The first parameter ‘frame_gray’ represents the image to be detected.

The second parameter ‘estimate_tag_pose=True’ represents whether to obtain tag pose.

The third parameter ‘camera_params=params’ represents camera parameters.

The fourth parameter ‘tag_size=TAG_SIZE’ represents the size of tag

Frame AprilTag ​

After AprilTag is found, frame it, and this program is as follow.

  1. Call ‘cv2.drawContours’ function to draw the contour of tag.

The first parameter ‘img’ represents specific tag image whose contour to be drawn.

The second parameter ‘corners’ represents contour

The third parameter ‘-1’ represents the index of contour. ‘-1’ represents all contours are drawn.

The fourth parameter ‘(255, 0, 0)’ represents color of contour. Three values in the bracket range from 0 to 255. Contour color is mixed by red, green and blue. The first value ‘255’ represents value of red, the second value ‘0’ represents value of green, and the third value represents value of blue.

The fifth parameter ‘3’ represents the width of contour.

  1. Call ‘cv2.circle’ function to draw the center of the tag

The first parameter ‘img’ represents the specific tag image whose center to be drawn.

The second parameter ‘tuple(center)’ represents the coordinate of center of the drawn circle which is determined by the detected object.

The third parameter ‘5’ represents the radius of the drawn circle.

The fourth parameter ‘(255, 255, 0)’ represents the color of the drawn circle. You can set this parameter in the same way as setting parameter 4 of drawing the contour of tag

The fifth parameter ‘10’ represents the width. The greater the value, the wider the border of circle.

Information Feedback ​

After tag is recognized, VNC software gives following feedback.

Program will draw 2 straight lines with ‘cv2.line’ function. The intersection corresponds to image center.

Take ‘cv2.line(img, (int(img_w / 2), int(img_h / 2 - 10)), (int(img_w / 2), int(img_h / 2 + 10)), (0, 255, 255), 2)’ for example.

The first parameter ‘img’ represents the specific image

The second parameter ‘(int(img_w / 2), int(img_h / 2 - 10))’ represents the coordinate of the start of straight line

The third parameter ‘(int(img_w / 2), int(img_h / 2 + 10))’ represents the coordinate of the end of straight line

The fourth parameter ‘(0, 255, 255)’ refers to color of straight line. You can set this parameter in the same way as setting parameter 4 of drawing the contour of tag

The fifth parameter ‘2’ represents the line width.

15.5 Lesson 6 Fingertips Control ​

The camera on robot arm should be adjusted to flat view.

15.5.1 Program Logic ​

JetMax Pro recognizes your fingertips trajectory to move its Mecanum wheel chassis.

Step 1: process image

Firstly, register and initialize the node of this game to ensure the program can run under ROS framework. Then, subscribe to topic ‘/usb_cam/image_rect_color’ published by camera node so as to obtain image data of the human face in front of the camera.

Next, convert ROS image into numpy image. Process image through flipping and converting color space to get ready for gesture detection.

Step 2: recognize and display

This step is realized by MediaPipe, a framework that is used to build cross-platform multi-mode machine learning models. Detect key point and target through calling API.

Firstly, import the processed detection image data to ‘process()’ to extract information so as to get the detected hand and coordinates of 21 key points.

Then, program prints index, score (recognition confidence) and label on the terminal.

Call API function ‘draw_landmarks()’ of MediaPipe to connect 21 hand keypoints to form a recognition map which can be displayed with “cv2.imshow()” function of OpenCV.

Get the trajectory of fingertips, and control Mecanum wheels to move according to the fingertip trajectory.

The source code of this program is stored in ‘/ros/src/chassis/scripts/fingertip_control.py’

15.5.2 Operation Steps ​

  1. Start JetMax Pro, and connect your computer to the WiFi generated by JetMax Pro

  2. Connect to robot system desktop through NoMachine. Double click to open terminal. (For how to install and use NoMachine, please refer to ‘7. Robot System Remote Connection’.) Robot system is as pictured.

  3. Click or press “Ctrl+Alt+T” to open terminal.

  4. Input command ‘cd ros/src/chassis/scripts/’ and press Enter to go to the directory where the game program is stored.

  5. Input command ‘./kill_app_funcs.sh’ and press Enter to close APP auto-start service.

  6. Input command “rosrun chassis fingertip_control.py” to start fingertips control. It takes about 30s to start the game. Please be patient!

  7. Input command “./restart_app_funcs.sh” to enable APP service. Do not skip this step, otherwise other games will be influenced.

After game starts, place your hand within the camera filed of view. When your hand is recognized, hand key points are marked on the camera returned image.

When JetMax Pro recognizes ‘1’ gesture, program will start recording the motion trajectory of your index fingertip. If motion trajectory is recognized, buzzer will beep once. If not, buzzer will beep twice. Once JetMax Pro recognizes ‘5’ gesture, the recorded trajectory on the camera returned image will be cleared.

15.6 Lesson 7 Target Tracking ​

The camera on robot arm should be adjusted to flat view.

15.6.1 Program Logic ​

JetMax Pro recognizes colored block through camera. Then locate the coordinate of the colored block. Lastly, Mecanum wheels are controlled by PID algorithm to move so as to let coordinate of colored block coincide with coordinate of camera returned image center. In this way, target tracking is achieved.

Step 1: color recognition

The program will recognize color before locating colored block. Firstly, converts RGB color space to Lab first. Following, perform image binarization, open operation and close operation to get the contour only in target color.

Next, traverse all contours in target color have been found, and calculate their area. Set area threshold to discard the contour whose area is too small. Lastly, find the maximum contour and maximum area.

Step 2: Color Tracking

After color is recognized, set the coordinate of current circle center of target contour as the initial value. Then calculate and update PID value according to real-time coordinate of circle center. Lastly, compute the speed of Mecanum wheels according to PID value.

The source code of this program is stored in

/ros/src/chassis/scripts/object_tracking.py

Call cv2.cvtColor() function to convert RGB color space into Lab color space.

After conversion, program will denoise the image that is use cv2.GaussianBlur() function to perform Gaussian filtering.

The first parameter ‘image’ represents the input image.

The second parameter ‘(5, 5)’ indicates the size of Gaussian kernel. Larger kernel results in greater filtering, and makes the output image fuzzier and computation more complicated.

The third parameter ‘5’ refers to the size of variance allowed around its average in Gaussian filtering. The greater the value, the greater variance allowed around its average.
