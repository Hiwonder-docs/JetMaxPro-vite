16.1 Lesson 2 Position Calibration ​

The purpose of position calibration is to convert robot arm’s coordinate on the phone to its real position. After position calibration, JetMax pro can better pick and sort objects.

Note: this lesson is exclusive to JetMax Pro. You need to install robot arm on sliding rail before operation. Please strictly follow instructions below and do not skip any step.

  1. Install and connect to WonderAi APP according to ‘1. Getting Ready>Lesson 6 APP Control’. Then tap robotic icon, and select ‘position calibration’.
  1. It is normal that the image transmitted by camera delays for a few seconds. If still no image occurs after a long time, return back to home interface, then tap and enter this interface again. Once camera returned image appears, tap ’Start position calibration’

  1. Place Tag block directly under the suction nozzle following the hints. Only if the suction nozzle is at the center of the block when the robotic arm bends down, you can click “Next”.

    Note: tag block is not fixed to the dotted box. It can be placed outside the dotted box.

  1. When 5 black dots on the screen coincide with 5 colored dots on the AprilTag block, please tap “Complete”.

16.2 Lesson 3 Handle Control ​

Step 1: insert the handle receiver to any USB port on Jetson Nano.

Note: please insert the handle receiver before starting the robot.

Step2: prepare two AAA batteries. Then insert them to battery slot. Please don’t invert ‘+’ and ‘-’ poles.

16.2.1 Device Connection ​

Step 1: start JetMax Pro

Step 2: turn on handle. At this time, two LED lights on it will flash at the same time.

Step 3: wait for a few seconds. JetMax Pro automatically matches with the handle. Green LED light will be on once they match successfully.

If handle does not connect to the robot within 30 seconds after turned on, or there is no operation on handle within 5 minutes after connection, handle will enter sleep mode. If you want to wake it up, press “START” key.

16.2.2 Introduction to Mode ​

There are two control modes, namely coordinate mode and individual servo mode. Handle enters individual servo mode by default after connection.

Individual servo mode: you can control servo separately on robot arm to rotate.

Coordinate mode: you can control robot arm to move in the direction of X, Y, Z axes.

Way to switch mode: press “SELECT” key. When handle emits sound, it means the mode is successfully switched. When sounding once, it is switched to coordinate mode. When sounding twice, it is switched to individual servo mode.

16.3 Lesson 4 Waste Sorting ​

The program sorts the waste cards based on the trained yolov5 model. Then control robot arm to suck cards and place them to specific position.

Step 1: Recognize and Sort

Firstly, subscribe to real-time image data published by camera node, then convert it to Numpy format. After conversion, transfer the image to yolov5 network to perform operations such as scaling, transposing, and array expansion so as to obtain processing results.

Convert the coordinate of the obtained waste cards into the coordinate of the original image. After the coordinate is converted, sort the waste according to the recognized waste name and the set rules, and get the corresponding waste category. Then, frame the waste and print its name and recognition confidence.

Step 2: Suck and Place

To ensure the credibility of the result, recognize the object for multiple times. After the target is confirmed, control robot arm to sort and transfer, and convert the pixel coordinate of the target card into world coordinate.

Calculate the angle between robot arm and central axis, and control suction nozzle to rotate to corresponding angle. Then control robot arm to move to the position where the card is placed, and let it suck the card. Next, set the sliding time of robot arm on the sliding rail according to the waste category to let robot arm slides to the position where the waste card of specific category should be placed, and put down the card.

The source code of this program is stored in

/ros/src/stepper/scripts/waste_classification_stepper.py

16.3.1 Operation Steps ​

  1. Start JetMax Pro, and connect your computer to WiFi generated by JetMax Pro.

  2. Connect to robot system desktop through NoMachine. Double click to open terminal. (For how to install and use NoMachine, please refer to ‘7. Robot System Remote Connection’.) Robot system is as pictured.

  3. Click or press “Ctrl+Alt+T” to open terminal.

  4. Input command ‘cd ros/src/stepper/scripts/’ and press Enter to go to the directory where the game program is stored.

  5. Input command ‘./kill_app_funcs.sh’ and press Enter to close APP auto-start service.

  6. Input command “rosrun stepper waste_classification_stepper.py” to start fingertips control. It takes about 30s to start the game. Please be patient!

  7. Input command “./restart_app_funcs.sh” to enable APP service. Do not skip this step, otherwise other games will be influenced.

16.3.2 Program Outcome ​

After the game starts, place the waste card within the recognition area on the map. Robot arm will place cards to specific area according to sorting result.

4.3 Convert Camera Coordinate to Real Coordinate

camer_to_world function is used to convert the coordinate on camera to real coordinate so as to get the real distance. The meaning of parameters of this function is as below.

Cam_mtx：

Transfer Cam_mtx to np.asmatrix.I function to get inverse matrix inv_k of cam_mtx

r：

Use np.zeros function to create empty matrix r_mat. Input r to cv2.Rodrigues function to convert vector to matrix and fill in r_mat. Then input r_mat into the np.asmatrix.I function to get the inverse matrix inv_r of r_mat.

t：

Input t into np.asmatrix to get new matrix, and input this new matrix and matrix inv_r into np.dot so as to compute the matrix transPlaneToCam required to convert coordinate.

Define the list world_pt = [] used for output

Define a new matrix coords

Define cyclic reading img_points, and name the content read each time img_pt, and put img_pt into corresponding empty matrix coords.

Use coords and inv_k to compute new matrix worldPtCam. Divide transPlaneToCam and worldPtCam to get the transformation coefficient scale.

scale times worldPtPlane to get the transformed matrix scale_worldPtPlane.

scale_worldPtPlane matrix subtracts transPlaneToCam matrix to get real coordinate worldPtPlaneReproject.

Define an empty matrix pt used to store coordinate, and assign the value of worldPtPlaneReproject to pt. Lastly, add pt to world_pt.

Get Image ​

Get the latest image to determine whether JetMax Pro is transferring object. If it is, the program will directly return, then obtain latest picture in loop.

Recognize Image ​

Convert ros image into OpenCV image, then use yolov5 trained model to recognize image. The recognition result is output to ‘boxes’, ‘confs’ and ‘classes’.

‘width’ and ‘height’ are the dimension of the image

Process Image Information ​

Map the result to the coordinate of the original image to obtain waste name and waste category.

Display Information ​

Display the recognized card information including, ID, position and name. Use corresponding color according to waste category.

Use cv2.putText() function to display the text on the image. Take ‘cv2.putText(image, waste_name + " " + str(float(cls_conf))[:4], (x1, y1 - 5), cv2.FONT_HERSHEY_SIMPLEX, 0.7, COLORS[waste_class_name], 2)’ for example.

The first parameter ‘image’ is the input image.

The second parameter ‘waste_name + " " + str(float(cls_conf))[:4]’ is the displayed text.

The third parameter ‘(x1, y1 - 5)’ The third parameter ‘(x1, y1 - 5)’ is the coordinate of the position where the text is displayed.

The fourth parameter ‘cv2.FONT_HERSHEY_SIMPLEX’ is the font type.

The fifth parameter ‘0.7’ is the font size.

The sixth parameter ‘COLORS[waste_class_name]’ is font color.

The seventh parameter ‘2’ is font weight.

Use cv2.rectangle() function to draw rectangle on the image. Take ‘cv2.rectangle(image, (x1, y1), (x2, y2), COLORS[waste_class_name], 3)’ for example.

The first parameter ‘image’ is the input image.

The second parameter ‘(x1, y1)’ is the coordinate of upper left corner of the rectangle.

The third parameter ‘(x2, y2)’ is the coordinate of lower right corner of the rectangle.

The fourth parameter ‘COLORS[waste_class_name]’ is the font color.

The fifth parameter ‘3’ is the width of the line

Transfer Sign ​

If no cards are recognized, set ‘cards’ as 0. Clear transfer flag variable ‘state.count’ as None, then recognize again.

If card is recognized but has not been recognized before, find the card with the maximum probability. Store this card as the target to be transferred.

If card is recognized and has also been recognized in last frame, find the card nearest to the camera recognized in this frame. If the distance between them is too long, set transferring flag as 0.

If the distance is appropriate, recognition is correct. JetMax Pro starts transferring after 50 times of correct recognition.

Go into child thread moving() function to let JetMax Pro suck waste card and place it to the specific position.

Motion Control Function ​

moving function is used to control sliding rail and robot arm to move.

Use hiwonder.pwm_servo1.set_position() function to control PWM servo to rotate. Take ‘hiwonder.pwm_servo1.set_position(90, 0.5)’ for example.

The first parameter ‘90’ is servo angle

The second parameter ‘0.5’ is running time of servo in second.

Use ‘jetmax.set_position()’ function to control robot arm to move. Take ‘jetmax.set_position((x, y, z), 0.8)’ for example.

The first parameter ‘(x, y, z)’ is the coordinate of the end of robot arm. (x, y, z), set in global variable, is the coordinate of position where the card is placed.

The second parameter ‘0.8’ is pitch angle.

16.4 Lesson 5 Tag Sorting ​

JetMax Pro recognizes the tag with its camera first, then place the tag block to specific position according to the recognized tag information and position.

AprilTag is a visual positioning tag similar to QR code or bar code.

Firstly, the program subscribes to information published by camera node to obtain real-time image data. After that, convert RGB color space to gray image. Following, read camera parameters.

Next, call AprilTag library function to detect AprilTag to get tag ID, get coordinate of four corners of the tag as well as the coordinate of the tag center.

Compute the recognized coordinate to get the coordinate of the block. Compute angle of the servo at the target position with inverse kinematics, then control robot arm to move to the target position and transfer the block to specific position according to its ID.

The source code of this program is stored in /ros/src/stepper/scripts/waste_classification_stepper.py
