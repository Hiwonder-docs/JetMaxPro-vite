Remote Tool Installation and Connection

7.1.1 NoMachine ​

7.1.2 Install NoMachine ​

  1. Install NoMachine. The installation pack “nomachine_7.1.3_1.exe” is stored in the same folder.

  2. Click ‘Next’.

  3. Select language to use, and tick “I accept the agreement”.

  4. Remain the default destination location

  5. It takes a few times to complete installation. Please be patient! Later on, click “Finish” when window below shows up.

  6. Click “Yes” to restart computer. Please don’t skip this step!

7.1.3 Device connection ​

You can connect to robot in three ways.

①AP direct connection: connect your phone to WiFi generated by Jetson Nano board. Jetson Nano cannot connect to external network in this mode.

②STA LAN mode: Jetson Nano automatically connects to specific hotspot/ WiFi.

③USB connection: connect Jetson Nano to computer through USB cable. Then input fixed IP to connect.

1.2.1 AP Direct Connection/ STA LAN Mode

  1. The default connection mode is AP direct connection mode. Once JetMax boots up successfully, it will create a Wi-Fi starting with HW. Connect your computer to this WiFi.
  1. Open NoMachine. Input ‘192.168.149.1’ in the search bar, then click ‘Configure connection to new host 192.168.149.1’.

  1. You can change the name as ‘JetMax’, and other settings remain the same. Click ‘Connect’

  2. Username is ‘hiwonder’, and password is ‘hiwonder’. Tick ‘Save this password’ and click ‘Login’ to get access to Jetson Nano desktop.

    Note: connection instructions under STA LAN mode are the same. You just need to change the corresponding IP, username and password in step 2, 3 and 4.

7.1.4 USB Connection ​

If you are using desktop computer, you can use remote NDIS compatible device to improve running.

  1. Connect JetMax to your computer through Micro USB cable.

  2. Right click ‘This computer’ to select ‘Manage’

  3. Click ‘device manager> network adapter>remote NDIS compatible device’. Then right click it to update driver.

  4. After installing the driver, login the system according to ‘2. Device Connection’. IP is ‘192.168.55.1’

  1. SSH Remote Connection

    You can get access to robot system through SSH. Compared to SSH, SSH cannot get access to robot system desktop and provide only command terminal making it convenient to control JetMax with command. Therefore you don’t need open too much windows, which saves computation and storage.

    1. Install SSH

  1. Find ‘putty-64bit-0.72-installer.msi’ file stored in ‘7. Robot System Remote Connection>Software’, and install it.

  2. Select folder, and click ‘Next’

  3. Install SSH

    Installation is completed when window below pops up.

    1. Use SSH

  4. After installation, open Putty software. Input IP ‘192.168.149.1’, and ensure the computer and JetMax connect to the same WiFi. Security alert window will show up, just click ‘yes’.

  5. Input username and password. Username and password are both hiwonder. Pay attention the content you input will be hidden, and you can press Enter once you finish.

    If the password is wrong, terminal will print ‘access denied’.

  6. Having successfully login JetMax system, you can control JetMax through command. To learn more about command, you can refer to ‘2. Linux Basic Lesson>Lesson 6 Common Linux Command’.
